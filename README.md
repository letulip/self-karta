# Карта экспертности

Само-интервью о сильных сторонах, энергии, ценностях и направлении — в браузере, без регистрации.
Человек проходит вопросы короткими сессиями, а в конце получает один Markdown-файл и готовый промпт для разбора
в своём ИИ-ассистенте.

Сайт: https://letulip.github.io/self-karta/

## Принципы

- **Ответы не покидают устройство.** Сервера, аккаунтов, аналитики и сторонних скриптов нет. Content-Security-Policy
  разрешает запросы только к самому сайту.
- **Прогресс не теряется.** Автосейв в `localStorage`, бэкап одним `.json`-файлом, слияние бэкапов по свежести каждого
  ответа. Safari стирает данные сайта через 7 дней без визитов, поэтому приложение напоминает о бэкапе и советует
  установить его на экран «Домой».
- **Три маршрута глубины**, вложенные друг в друга: Эскиз (45 вопросов) ⊂ Карта (100) ⊂ Атлас (158).

## Вопросы

Источник правды — [`src/content/questions.ru.ts`](src/content/questions.ru.ts). Вопросы собраны из двух само-интервью,
подготовленных с помощью Claude (C1–C100) и ChatGPT (G1–G100): 42 вопроса G по смыслу совпали с вопросами C и
показываются как «ещё угол», остальные 58 — отдельными вопросами.

- `id` вопроса стабилен: к нему привязаны сохранённые ответы. Не переименовывай id, а при правке формулировок
  увеличивай `QUESTIONS_VERSION` — она попадает в выгрузку.
- Тексты интерфейса, цели, промпты разбора и шаги «что делать с результатом» — в
  [`src/content/texts.ru.ts`](src/content/texts.ru.ts).
- Тесты `tests/unit/content.test.ts` проверяют, что все 200 исходных номеров учтены ровно один раз, маршруты вложены,
  а формулировки нейтральны по роду.

## Разработка

```bash
npm install
npm run dev          # http://localhost:5173/self-karta/
npm test             # unit-тесты (Vitest)
npm run e2e          # сценарии в Playwright поверх продакшен-сборки, десктоп и телефон
npm run check        # типы + unit + сборка + e2e
```

Перед релизом — проверка, что в код и сборку не попал ни один фрагмент личных ответов (папка с ними передаётся
аргументом и в репозиторий не кладётся):

```bash
npm run leak-check -- ~/path/to/private-answers
```

## Публикация

Каждый push в `main` запускает `.github/workflows/deploy.yml`: тесты, сборка и публикация на GitHub Pages.
Один раз нужно включить Pages: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
